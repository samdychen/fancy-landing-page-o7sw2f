# Elevate Landing Page

A modern, fancy landing page built with React and Tailwind CSS.

## Project Structure

- `index.html` - Main landing page
- `pricing.html` - Pricing page
- `app.js` - Main application component
- `pricing-app.js` - Pricing page app component
- `components/` - React components
  - `Header.js` - Navigation header (shared)
  - `Hero.js` - Hero section with CTA
  - `Features.js` - Features showcase
  - `Stats.js` - Statistics section
  - `CTA.js` - Call-to-action section
  - `Footer.js` - Footer with links (shared)
  - `PricingHero.js` - Pricing page hero
  - `PricingPlans.js` - Pricing plans comparison
  - `PricingFAQ.js` - Pricing FAQ section

## Design System

- **Primary Color**: Indigo (#6366f1)
- **Typography**: System fonts with bold headings
- **Style**: Modern gradient-based design
- **Layout**: Responsive with max-width container

## Features

- Smooth scrolling navigation
- Multi-page structure (Landing + Pricing)
- Gradient backgrounds and text
- Responsive design
- Modern UI components
- Interactive pricing plans with FAQ
- Clean and professional layout
